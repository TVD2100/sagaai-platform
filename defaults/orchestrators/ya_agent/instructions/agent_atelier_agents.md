# Агенты Agent Atelier: вызов сохранённых агентов

Эта инструкция описывает особенности запросов к агентам, созданным в конструкторе **Agent Atelier** Yandex AI Studio. Она дополняет инструкции `agents_responses_api` (эндпоинты, параметры) и `yandex_models_reference` (выбор модели).

## Чем сохранённый агент отличается от обычной модели

Обычный вызов модели использует `model: "gpt://<folder_id>/<имя_модели>"`. Агент Agent Atelier - это готовая конфигурация на стороне сервиса: системный промпт-шаблон с переменными, подключённые инструменты (web_search, file_search и др.) и выбранная модель. Вызов идёт **по ID агента**, а не по URI модели:

```python
response = client.responses.create(
    prompt={
        "id": AGENT_ID,
        "variables": {"ORG_LIST": org_list},
    },
    input=user_input,
)
```

## Формат вызова (проверенный рабочий пример)

```python
import os
import openai

AGENT_ID = "AGENT_ID"
BASE_URL = "https://ai.api.cloud.yandex.net/v1"

api_key = os.getenv("api_key")
folder_id = os.getenv("folder_id_key")

client = openai.OpenAI(
    api_key=api_key,
    project=folder_id,
    base_url=BASE_URL,
)

response = client.responses.create(
    prompt={
        "id": AGENT_ID,
        "variables": {"ORG_LIST": "ООО Ромашка, ООО Василёк, АО Заря"},
    },
    input=(
        "Найди и обобщи информацию из интернета по каждой компании из списка "
        "и приведи справки об их основных видах деятельности. "
        "Не задавай никаких уточняющих вопросов - просто выполни задание."
    ),
)
print(response.output_text)
```

Ключевые моменты:

- `AGENT_ID` - строка вида `fvt9ve1csv6daednsuqk`, берётся из интерфейса Agent Atelier.
- `model` в запросе НЕ передаётся: модель задаётся в настройках самого агента.
- `input` - сообщение пользователя (строка).
- `project=folder_id` в OpenAI SDK обязателен, как и для обычных вызовов.

## Переменные шаблона

- В инструкции агента переменные записываются **двойными фигурными скобками**: `{{ORG_LIST}}` (не одинарными).
- Значения передаются словарём в `prompt.variables`; ключ словаря должен совпадать с именем переменной в шаблоне.
- Сервер подставляет значения в шаблон при выполнении запроса.
- В ответе API поле `instructions` может возвращаться как `None` - это норма: сервер не отдаёт наружу раскрытый текст промпта, но подстановку выполняет. Ориентироваться на `response.instructions` не нужно; проверяйте фактическое поведение агента по ответу.
- Если переменных несколько - передавайте все в `variables`.

## Инструменты и системный промпт

- Инструменты (web_search, file_search и т.п.) подключаются к агенту в Agent Atelier - в запросе их передавать не нужно.
- Системный промпт тоже хранится в агенте. Если нужно изменить поведение - редактируйте агента в Agent Atelier, а не пытайтесь переопределить инструкции в запросе.

## Параметры генерации

Минимальный рабочий вызов - `prompt` + `input`. Обычные параметры Responses API могут комбинироваться с `prompt`, но их поведение для сохранённых агентов проверяйте на конкретной конфигурации.
