# Мультимодальные сервисы Yandex Cloud в агентах

Эта инструкция описывает, как встраивать мультимодальные сервисы Yandex Cloud (SpeechKit, Vision OCR, Translate, генерация изображений) в агентные решения на базе Yandex AI Studio. Используется вместе со справочником моделей (`yandex_models_reference`) и инструкцией по Responses API (`agents_responses_api`).

## Доступ и роли

Роль `ai.models.user` (или выше) на каталог даёт право использовать сервисы Yandex Translate, Yandex Vision OCR и Yandex SpeechKit, а также модели генерации текста, изображений, эмбеддингов и классификаторы. Назначение ролей выполняется в Yandex IAM на организацию, облако или каталог (наследуется вложенными ресурсами).

## SpeechKit

SpeechKit доступен по адресам:
- Синтез речи (TTS): `tts.api.cloud.yandex.net:443`.
- Распознавание речи (STT): `stt.api.cloud.yandex.net:443`.

### Синтез речи (text-to-speech)

- Озвучивание текста на нескольких языках; технология глубоких нейросетей оценивает текст целиком - чистое естественное звучание без электронных искажений.
- API: v1 (REST) и v3 (gRPC и REST); v3 предпочтителен для новых решений.
- Поддерживаются потоковый синтез, управление скоростью, громкостью, произношением (включая IPA/SSML-подобные подсказки).
- Доступны различные голоса и роли.

### Распознавание речи (speech-to-text)

- Потоковое распознавание (режим реального времени) - подходит для голосовых чатов и Realtime API.
- Распознавание аудиофайлов: синхронное (короткие аудио) и асинхронное (длинные файлы).
- Поддерживаются разные форматы аудио (см. документацию: `supported_audio_formats_in_speechkit.md`).
- При работе с AI Studio удобно использовать `speech_recognition_via_ai_studio_playground.md` для тестирования.

### Встраивание в агентов

- **Голосовые агенты**: Realtime API + потоковое распознавание + синтез - эффект «живого» общения.
- **Озвучивание ответов**: TTS v3 после генерации текстового ответа.
- **Транскрибация входящих аудио**: STT с последующей обработкой текста моделью.

## Vision OCR

Распознавание текста на изображениях и в документах. Поддерживаются две модели:
- `page` - для печатного текста любого объёма;
- `handwritten` - для рукописного текста.

### Требования к файлам

- Форматы: JPEG, PNG, PDF.
- MIME-тип: по умолчанию `image`; для PDF - `application/pdf`.
- Максимальный размер файла: 10 МБ.
- Изображение не более 20 мегапикселей (ширина × высота).
- Файл передаётся в запросе в кодировке Base64.

### Встраивание в агентов

- Извлечение текста из счетов, документов, визиток, рукописных заметок.
- Подготовка контента для RAG (распознанный текст -> база знаний).
- Валидация и обработка документов в бизнес-процессах.

## Yandex Translate

- Более 100 языков; перевод слов и целых текстов.
- Автоматическое определение языка исходного текста (можно использовать только для определения языка).
- **Глоссарии** - словарь слов/словосочетаний с однозначным переводом для специфических тем: повышают точность перевода.
- Операции: перевод текста, повышение точности, определение языка, получение списка поддерживаемых языков.

### Встраивание в агентов

- Перевод пользовательских запросов/ответов;
- Мультиязычные ассистенты с сохранением смысла терминов через глоссарии;
- Определение языка входящего текста для маршрутизации.

## Генерация изображений

Две модели (детали - в справочнике моделей `yandex_models_reference`):
- **Alice AI ART** (`art://<каталог>/aliceai-image-art-3.0`) - диффузионная мультимодальная, учитывает культурный контекст, хорошо генерирует текст на русском. OpenAI-совместимый Images API + Image Generation Tool через Responses API.
- **YandexART** (`art://<каталог>/yandex-art-2.0`) - каскадная диффузия; параметр `mime_type` (image/jpeg), 1024x1024 по умолчанию, размер может отклоняться до 10%. Собственный API (REST/gRPC). Доступна до 18 августа 2026.

Лимиты генерации изображений: 500 запросов/мин, 5 000 в сутки; максимальная длина промпта - 500 символов; хранение сгенерированных изображений - 12 часов.

### Встраивание в агентов

- Image Generation Tool в Responses API: модель сама решает, когда вызвать генерацию.
- Иллюстрации, рекламные материалы, карточки товаров, презентации.
- Зерно генерации (seed) позволяет повторять результат при том же промпте (для YandexART: 0 ... 2^63-1).

## Рекомендации при проектировании

1. **Выбирайте API v3** для SpeechKit, если это возможно; v1 сохраняется для совместимости.
2. **Vision OCR** - явно выбирайте модель `page` или `handwritten` по типу входящего текста.
3. **Глоссарии Translate** - обязательны для доменной лексики (юриспруденция, медицина, продукты).
4. **Асинхронные операции** - для длинных аудио и больших объёмов используйте асинхронные вызовы, а не синхронные.
5. **Кодирование файлов** - всегда Base64, с указанием правильного MIME-типа.
6. **Промпты изображений** - не длиннее 500 символов; для воспроизводимости сохраняйте seed.
