# 📖 SagaAI 用户指南

## 🌟 概述

SagaAI 是一个基于大语言模型的通用 AI 平台，您可以在其中创建自己的 AI 助手和数字员工。

🔹 **新对话** - 与您创建的 AI 助手聊天，附加文件，搜索网页。
🔹 **助手** - 通过独特的提示词和文件创建可重用的 AI 专家。
🔹 **员工** - 基于协调器的 AI 代理，具有灵活的设置，可处理复杂的工作流程。
🔹 **DevAgent** - 通用 AI 开发者，用于阅读、编辑和创建代码，自动备份。
🔹 **历史记录** - 所有对话均已保存，可搜索和恢复。
🔹 **多语言** - 支持俄语、英语、中文等多种界面语言。

---

## 🚀 如何开始

以下是充分发挥 SagaAI 功能的正确设置顺序。

### 1. ⚙️ 配置大语言模型

> **页面：** 设置 → 提供商

首先连接 AI 服务 - 否则平台无法响应。

- 为所需服务添加 API 密钥（兼容 OpenAI、YandexAI、GigaChat 等）。
- 点击«🔍 测试连接»按钮测试连接。
- 选择默认模型。

💡 **提示：** 也可通过环境变量 `SAGAAI_<服务>_KEY` 设置 API 密钥 - 更安全。

### 2. 🔧 配置 DevAgent

> **页面：** 侧边栏 → DevAgent → «设置»选项卡

DevAgent 是您的 AI 程序员。配置它：

- **强模型** - 用于编写代码、规划和复杂任务。
- **弱模型** - 用于快速操作（读取文件、备份）。
- **网络搜索模型** - 使 DevAgent 能搜索互联网。
- **经济模式** - 减少长会话的 token 消耗。

💡 **提示：** 强模型选择强大的模型，弱模型选择更便宜/快速的模型。

### 3. 🧩 创建助手

> **页面：** 设置 → 助手

助手是具有独特系统提示词的 AI 专家。

- 前往设置 → 助手，点击«+ 创建助手»。
- 设置名称、系统提示词并选择模型。
- 可选附加上下文文件（.txt、.pdf、.md 等）。
- 在侧边栏中选择就绪的助手，即可立即开始聊天。

💡 **示例：** «翻译器»、«校对员»、«导师» - 可能性仅受提示词限制。

### 4. 👥 创建员工

> **页面：** 设置 → 员工

员工是基于协调器的高级 AI 代理，具有自定义设置、指令和 Python 函数。它们可以根据您的脚本执行复杂的工作场景。

- 点击«🛠 通过 DevAgent 创建员工» - DevAgent 会进行问卷调查并完成所有设置。
- 或打开 DevAgent 并直接请求：«创建一个用于代码测试的员工»。
- 员工可拥有自己的 Python 函数、专门的指令和模型。

💡 **示例：** «数据分析师»、«SEO 优化师»、«项目经理»。

## 📋 主要功能

| 功能 | 描述 |
|---|---|
| 🧩 **助手** | 带有提示词和文件的可重用 AI 专家 |
| 👥 **员工** | 基于协调器的 AI 代理，带有函数和技能 |
| 🔧 **DevAgent** | 用于编辑任意代码、自动备份、测试的代理 |
| 🌐 **网络搜索** | AI 在需要时搜索互联网 |
| 🔢 **多模型** | 强 + 弱 + 搜索模型，适用于不同任务 |
| 💡 **经济模式** | 紧凑上下文以节省 token |
| 📜 **历史** | 所有对话均已保存、可搜索和恢复 |
| 🌍 **语言** | 支持俄语、英语、中文等多种界面 |

---

## 🛡️ 安全

- DevAgent 在每次文件更改前**自动创建备份**。
- 您可以从系统快照中恢复单个文件或整个项目。
- 认证系统保护平台的访问权限。

---

## 🔢 界面语言

在侧边栏中选择语言（🌐 语言）。支持：
- 🇷🇺 俄语
- 🇬🇧 英语
- 🇨🇳 简体中文

欢迎页面和所有界面元素将自动适应所选语言。
