# SagaAI - сравнительный анализ и позиционирование

**Версия 1.0** · Официальный документ для пользователей и сообщества

SagaAI - открытая платформа для создания и управления **командой ИИ-сотрудников**: чат-ассистенты, автономные оркестраторы, базы знаний (RAG) и встроенный агент-разработчик DevAgent - в едином веб-интерфейсе с фокусом на контроль, расширяемость и защиту данных.

Этот документ показывает, чем SagaAI отличается от ближайших категорий открытых продуктов:

| Категория | Проекты |
| - | - |
| Персональные ИИ-ассистенты | OpenClaw, Hermes Agent |
| Кодинг-агенты | Claude Code, OpenAI Codex CLI |
| Агентные харнессы и платформы | DeepSeek Harness |


## 1. SagaAI vs персональные ИИ-ассистенты

OpenClaw и Hermes Agent - одиночные ассистенты, живущие в мессенджерах. SagaAI - многоагентная платформа, в которой можно создавать нескольких агентов с разными ролями, подключать базы знаний и использовать агента-разработчика.

| Критерий | **SagaAI** | **OpenClaw** | **Hermes Agent** |
| - | :-: | :-: | :-: |
| **Суть** | Платформа для создания и управления командой ИИ-сотрудников в веб-интерфейсе | Персональный ИИ-ассистент, живущий в мессенджерах | Автономный персональный агент с непрерывным обучением и памятью |
| **Форма-фактор** | Веб-приложение (self-hosted) | Локальный сервер + боты мессенджеров | Локальный агент + боты мессенджеров |
| **Основной интерфейс** | Браузер: чат, помощники, оркестраторы, история, настройки, хранилище RAG | Telegram, Discord, WhatsApp, Slack и др. + веб-панель | Telegram, Discord, Slack, WhatsApp, Signal |
| **Мультиагентность** | ✅ Оркестраторы-сотрудники и ИИ-помощники с собственными ролями | ❌ Один ассистент | ❌ Один агент |

## 3. SagaAI vs DeepSeek Harness

DeepSeek Harness (dsh) - открытый агентный харнесс от DeepSeek AI: модульный рантайм для построения автономных агентов с философией «Everything is a Plugin» и веб-интерфейсом. Это ближайший по духу «платформенный» конкурент, однако SagaAI идёт дальше: она включает готовых сотрудников, RAG-базы, агента-разработчика и систему навыков «из коробки».

| Критерий | **SagaAI** | **DeepSeek Harness (dsh)** |
| - | :-: | :-: |
| **Тип** | Готовая платформа: ассистенты + оркестраторы + DevAgent + RAG | Агентный харнесс / рантайм для сборки агентов |
| **Лицензия** | Не определена | MIT |
| **Интерфейс** | Веб-UI (чат, управление, история, настройки, RAG) | Web UI + CLI, терминальные сессии |
| **Философия** | «Всё в одном» для ИИ-команд: сотрудники, знания, разработка | «Everything is a Plugin»: модель и инструменты как плагины |
| **Мультиагентность** | ✅ Оркестраторы-сотрудники с ролями и настройками | ❌ Один агент в рантайме |
| **Встроенный агент-разработчик** | ✅ DevAgent (бэкапы, снапшоты, пайплайн тестов) | ❌ Нет (через плагины возможно) |
| **RAG / базы знаний** | ✅ Встроенные векторные базы | ❌ Нет (через плагины возможно) |
| **Навыки / расширения** | ✅ Стандартизированные навыки, создание по запросу, адаптация чужих навыков | ✅ Плагины (модели, инструменты, UI) |
| **Память и задачи** | ✅ Треды, TASK_STATE.md, история сотрудников | Сессии, логи, плагины |

## 5. Уникальные возможности SagaAI

### 5.1. Встроенный дефолтный агент YaAgent

SagaAI поставляется с готовым дефолтным оркестратором **YaAgent** - агентом по разработке и тестированию агентов и мультиагентных систем на базе **Yandex AI Studio**. YaAgent:

- ищет официальную документацию Yandex AI Studio в вебе и использует локальный каталог документации;

- работает со встроенной RAG-базой `yaagentai_2020` (семантический поиск по базе знаний YaAgentAI);

- натренирован на задачи разработки и отладки агентов, включая интеграцию с Yandex-сервисами;

- использует эконом-режим с кэшированием контекста для снижения стоимости.

YaAgent - это «первый сотрудник» после системного DevAgent, который работает сразу после установки, без настройки.

### 5.2. Создание навыков по запросу

Пользователь может попросить платформу создать новый **навык** на естественном языке: система сформирует стандартизированный пакет навыка (инструкции `SKILL.md` / `AGENT_SYSTEM_PROMPT.md`, файлы, метаданные), зарегистрирует его в библиотеке навыков и сделает доступным оркестраторам. Навыки можно создавать, просматривать, включать и отключать - без правки кода.

### 5.3. Нативная поддержка и адаптация навыков от других платформ

SagaAI использует открытый, документированный формат навыков, что позволяет **адаптировать навыки из других экосистем ИИ-агентов** (например, навыки персональных ассистентов вроде OpenClaw/ClawHub и аналогичных платформ). Навык переносится в библиотеку SagaAI, при необходимости нормализуется под стандарт платформы и сразу становится доступен оркестраторам и DevAgent.

### 5.4. Саморефлексия и самодоработка

Платформа включает встроенные механизмы **саморефлексии и самодоработки**:

- **Саморефлексия** - регламентированная процедура разбора завершённых задач: что пошло не так, корневые причины и конкретные улучшения процессов;

- **Самодоработка инструкций** - оркестратор может создавать и обновлять собственные инструкции (`save_orchestrator_instruction`), закрепляя накопленный опыт;

- **Самодоработка функций** - управление пользовательскими функциями оркестратора (`save_orchestrator_function`) для расширения инструментария;

- **Самодоработка навыков** - создание и доработка навыков по запросу и по итогам саморефлексии;

- **Мета-инструменты** - Assistant Creator и Employee Creator автоматически генерируют и улучшают системные промпты новых ассистентов и сотрудников.

> Отличие от Hermes Agent: у Hermes самодоработка реализована как автоматический «замкнутый контур обучения» (агент сам создаёт переиспользуемые навыки и сохраняет память между сессиями). В SagaAI саморефлексия и самодоработка - управляемые процедуры: пользователь и оркестратор могут в явном виде анализировать завершённые задачи, править инструкции, функции и навыки, а также создавать новых ассистентов и сотрудников через мета-инструменты.

### 5.5. Коннекторы к внешним сервисам

SagaAI умеет подключать внешние сервисы к сотрудникам и DevAgent:

- подключение внешних сервисов (сейчас - GitHub) с хранением токенов в защищённом виде (криптографически защищены от восстановления без ключа);

- страница **«Коннекторы»** для создания, проверки, редактирования и удаления подключений;

- вкладка **«Подключения»** в настройках сотрудника: включение коннекторов для конкретного агента;

- при включённом GitHub-подключении оркестратор получает инструменты `github_list_repos`, `github_create_repo`, `github_upload_file`, `github_update_file`, `github_read_file` и инструкцию `github_connector`.

## 6. Позиционирование SagaAI

SagaAI занимает уникальную нишу между тремя категориями:

| Категория | Что предлагают они | Что добавляет SagaAI |
| - | - | - |
| Персональные ассистенты (OpenClaw, Hermes) | Один ассистент в мессенджерах | Команда ИИ-сотрудников в веб-интерфейсе, RAG, защита данных |
| Кодинг-агенты (Claude Code, Codex) | Терминальный агент для кода | Платформа с DevAgent + ассистентами + знаниями + документацией |
| Харнессы (DeepSeek Harness) | Рантайм, который надо собирать | Готовая платформа «из коробки» с дефолтными агентами |


### Ключевое ценностное предложение

> **SagaAI - это не «очередной ИИ-ассистент» и не «очередной кодинг-агент», а единая открытая платформа для создания и управления командой ИИ-сотрудников: чат-ассистенты, автономные оркестраторы, базы знаний и встроенный агент-разработчик - с веб-интерфейсом, самодоработкой навыков и средствами защиты данных.**

### Главные отличия

1. **ИИ-команда, а не один ассистент** - оркестраторы-«сотрудники» с собственными ролями, промптами, моделями, инструментами, инструкциями, функциями и навыками.

2. **Встроенный агент-разработчик** - DevAgent с утверждаемым редактированием, версионированием файлов, снапшотами проекта и регламентированным пайплайном тестирования.

3. **Знания под контролем** - встроенные RAG-базы знаний с векторным индексом и семантическим поиском.

4. **Расширяемость** - создание навыков по запросу и адаптация навыков из других экосистем.

5. **Самосовершенствование** - саморефлексия и самодоработка инструкций, функций и навыков.

6. **Защита данных для бизнеса** - хранение ключей в защищённом виде, TLS-верификация, опциональная аутентификация, санитизация и разметка недоверенных данных.

7. **Open Source** - публикация под открытой лицензией (еще не определена) с контролем автора над развитием.
