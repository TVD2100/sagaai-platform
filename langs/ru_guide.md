# 📖 Руководство пользователя SagaAI

## 🌟 Обзор

SagaAI - это универсальная ИИ-платформа на базе больших языковых моделей, на которой вы можете создавать своих ИИ-помощников и цифровых сотрудников.

🔹 **Новый диалог** - общайтесь с созданными ИИ-помощниками, прикрепляйте файлы, ищите информацию в интернете.
🔹 **Помощники** - создавайте переиспользуемых ИИ-экспертов с уникальными промптами и файлами.
🔹 **Сотрудники** - ИИ-агенты на базе оркестратора с гибкими настройками для выполнения сложных рабочих процессов.
🔹 **DevAgent** - универсальный ИИ-разработчик для чтения, правки и создания кода с авто-бэкапами.
🔹 **История** - все диалоги сохраняются, доступны для поиска и восстановления.
🔹 **Многоязычность** - русский, английский, китайский и другие языки интерфейса.

## 🚀 Как начать

Ниже - правильный порядок настройки SagaAI для полноценной работы.

### 1. ⚙️ Настройка LLM

> **Страница:** Настройки → Провайдеры

Прежде всего подключите ИИ-сервисы - без них платформа не сможет отвечать.

- Добавьте API-ключи для нужных сервисов (OpenAI-совместимые, YandexAI, GigaChat и др.).
- Проверьте подключение кнопкой «🔍 Проверить подключение».
- Выберите модель по умолчанию.

💡 **Совет:** API-ключи также можно задать через переменные окружения `SAGAAI_<СЕРВИС>_KEY` - тогда они не сохраняются в базе данных.

### 2. 🔧 Настройка DevAgent

> **Страница:** Боковое меню → DevAgent → кнопка ⚙️ «Настройки» в панели чата. Также с приветственной страницы: шаг 2 («🔧 Настройка DevAgent») ведёт сразу в настройки.

DevAgent - это ваш ИИ-программист. Настройте его:

- **Сильная модель** - для написания кода, планирования и сложных задач.
- **Слабая модель** - для быстрых операций (чтение файлов, бэкапы).
- **Модель веб-поиска** - чтобы DevAgent мог искать информацию в интернете.
- **Экономичный режим** - снижает расход токенов при длинных сессиях.

💡 **Совет:** для сильной модели выбирайте мощные модели, для слабой - более дешёвые/быстрые.

### 3. 🧩 Создание помощников

> **Страница:** Настройки → Помощники

Помощники - это ИИ-эксперты с уникальными системными промптами.

- Перейдите в раздел Настройки->Помощники. Нажмите «+ Создать помощника».
- Задайте имя, системный промпт и выберите модель.
- При необходимости прикрепите файлы контекста (.txt, .pdf, .md и др.).
- Готового помощника можно выбрать в боковом меню и сразу начать чат.

💡 **Примеры:** «Переводчик», «Корректор», «Тьютор» - возможности ограничены только вашим промптом.

### 4. 👥 Создание сотрудников

> **Страница:** Настройки → Сотрудники

Сотрудники - это продвинутые ИИ-агенты на базе оркестратора с собственными настройками, инструкциями и Python-функциями. Они могут выполнять сложные рабочие сценарии согласно вашим сценария. 

- Нажмите «🛠 Создать сотрудника через DevAgent» - DevAgent проведёт опрос и настроит всё сам.
- Или откройте DevAgent и просто попросите: «Создай сотрудника для тестирования кода».
- Сотрудники могут иметь собственные функции на Python, специфичные инструкции и модель.

💡 **Примеры:** «Специалист по анализу данных», «SEO-оптимизатор», «Менеджер проекта».

## 📋 Основные возможности

| Возможность | Описание |
|---|---|
| 🧩 **Помощники** | Переиспользуемые ИИ-эксперты с промптами и файлами |
| 👥 **Сотрудники** | ИИ-агенты-оркестраторы с функциями и навыками |
| 🔧 **DevAgent** | Агент для редактирование любого кода, авто-бэкапы, тестирование |
| 🌐 **Веб-поиск** | ИИ ищет информацию в интернете при необходимости |
| 🔢 **Мультимодельность** | Сильная + слабая + поисковая модель для разных задач |
| 💡 **Экономичный режим** | Компактный контекст для экономии токенов |
| 📜 **История** | Все диалоги сохраняются, их можно найти и восстановить |
| 🌍 **Языки** | Интерфейс на русском, английском, китайском и др. |

## 🛡️ Безопасность и защита данных

- DevAgent **автоматически создаёт резервную копию** перед каждым изменением файла.
- Вы можете восстановить отдельный файл или весь проект из снимков системы.
- Опциональная аутентификация позволяет ограничить доступ к платформе паролем.
- API-ключи, сохраняемые в базе данных, хранятся в защищённом виде; ключ для их восстановления находится вне папки с данными.
- API-ключи можно задать через переменные окружения - тогда они не сохраняются в базе данных.
- DevAgent защищает себя от prompt-injection: содержимое файлов, результаты инструментов и веб-поиска помечаются как данные и очищаются от управляющих символов.
