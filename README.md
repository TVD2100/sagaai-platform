# SagaAI - Универсальный AI-ассистент

SagaAI - это многофункциональная платформа по созданию ИИ-сотрудников и помощников, которая объединяет лучшее из мира персональных ассистентов, кодинг-агентов и агентных платформ в одном продукте. 

> 🚧 **Статус версии: preview (v0.1.0-preview.1).** Проект находится на стадии предварительного выпуска: интерфейс, API и форматы данных могут меняться между версиями без предупреждения до выхода стабильного релиза. Для критичных задач пока не рекомендуется.

Не рекомендуется к использованию лицами без соответствующей технической квалификации.
>
> В силу особенностей работы больших языковых моделей - включая галлюцинации и некорректную интерпретацию поставленных задач - автономные агенты могут в процессе выполнения задач причинить ущерб как пользователю, так и третьим лицам. Используя данное программное обеспечение, пользователь принимает на себя полную ответственность за действия, совершаемые ИИ-агентами.

## 🚀 Возможности

### 💬 Чат с AI

- Поддержка OpenAI-совместимых API (YandexAI, DeepSeek) и GigaChat.

- Прикрепление файлов - текстовых, PDF, офисных форматов (docx, pptx, xlsx) с автоматическим извлечением содержимого.

- Рендеринг ответов в Markdown с подсветкой синтаксиса и кнопкой копирования.

### 🧩 Помощники

- Создание, редактирование и удаление помощников (системных промптов) с привязкой файлов.

- Автоматический подбор подходящего AI-сервиса и модели при создании помощника (анализ сложности задачи).

- Automatic prompt improvement: улучшение промптов помощников с помощью слабой модели DevAgent.

- Assistant Creator - встроенный мета-инструмент для генерации качественных промптов.

### 👥 Сотрудники (оркестраторы)

- **Оркестратор** - автономный AI-агент (как DevAgent) со своим системным промптом, настройками моделей, эконом-режимом и набором инструментов, инструкциями и функциями. В интерфейсе такие агенты называются сотрудниками.

- Каждый оркестратор - отдельная страница в меню с чатом, а также отдельная страница настроек.

- **Настройки** включают: выбор сильной/слабой/поисковой модели, системный промпт, эконом-режим, инструкции, функции, навыки, базы знаний и подключения.

- Экспорт/импорт оркестраторов реализован в ядре (`core.orchestrators`, формат `sagaai_orchestrator/v1`); UI-интерфейс для экспорта/импорта намеренно отложен.

- DevAgent - встроенный оркестратор (неудаляемый), всегда доступен.

### 🔧 DevAgent - агент-разработчик

- Редактирование кода с утверждением изменений: каждое изменение проходит стадию предложения (`propose_file`) и требует утверждения пользователем.

- Автоматическое версионирование файлов (бэкапы) и возможность полного отката проекта (снапшоты).

- Dual-model routing: автоматический выбор сильной/слабой модели в зависимости от сложности шага.

- Защита от path traversal: инструменты не могут выйти за пределы рабочей папки.

- Inviolable Core: физический запрет на изменение критичных файлов DevAgent.

- Санитизация и разметка недоверенных данных: файлы пользователя, результаты инструментов и веб-поиска помечаются как DATA и очищаются от управляющих символов перед отправкой модели.

- Эвристическая защита от prompt-injection: подозрительный контент заменяется заполнителем.

- Внешняя память задач (`TASK_STATE.md`) для сложных многоэтапных работ.

### 🌐 Универсальный разработчик

- Подключайте любую папку с проектом - DevAgent проанализирует структуру, построит карту (`PROJECT_MAP.md`) и будет работать с ней как с собственной кодовой базой.

- Автоматическое ведение документации: спецификация, архитектура, changelog.

### 🧠 Библиотека навыков

- Стандартизированная библиотека навыков: пакеты инструкций и скриптов, которые можно включать для сотрудников и DevAgent.

- Создание навыков по запросу и адаптация навыков из других экосистем ИИ-агентов с отметкой о статусе адаптации.

### 🔗 Коннекторы

- Подключение внешних сервисов (сейчас - GitHub) с хранением токенов в защищённом виде.

- Страница **«Коннекторы»** для создания, проверки, редактирования и удаления подключений.

- Вкладка **«Подключения»** в настройках сотрудника позволяет включить коннекторы для агента.

- При включённом GitHub-подключении оркестратор получает инструменты `github_list_repos`, `github_create_repo`, `github_upload_file`, `github_update_file`, `github_read_file` и инструкцию `github_connector`.

### 📚 Базы знаний (RAG)

- Создание локальных баз знаний с векторным индексом для семантического поиска.

- Загрузка документов, автоматическая индексация (чанкинг + эмбеддинги через Yandex Embeddings API).

- Поиск релевантных фрагментов при ответе на запросы.

- Страница **«Хранилище»** для управления базами: список, создание, файлы, индексация, тестовый поиск.

- DevAgent и оркестраторы могут обращаться к базам напрямую через инструменты `list_rag_bases()` и `rag_search()`.

### 📊 Статистика

- Страница **«Статистика»** с агрегацией расхода токенов по периодам, поставщикам и моделям на основе диалогов помощников и сотрудников.

### 🛡️ Защита данных

- **TLS-верификация** включена по умолчанию для всех запросов к AI-сервисам.

- **Опциональная аутентификация** по паролю для ограничения доступа к приложению.

- **Хранение API-ключей**: ключи, сохраняемые в базе данных, хранятся в защищённом виде; ключ для их восстановления находится вне папки с данными (`SAGAAI_ENCRYPTION_KEY` или отдельный файл).

- API-ключи можно задать через переменные окружения - в этом случае они не сохраняются в БД.

- UI-маскировка секретов: ключи не отображаются в открытом виде.

> ⚠️ Проект находится на ранней стадии: перечисленные выше механизмы реализованы, но независимого аудита безопасности ещё не проводилось.

### 🎨 Темы оформления

- Переключение темы интерфейса: светлая, тёмная или системная.

### 🌍 Многоязычность

- Интерфейс переведён на русский, английский и китайский языки.

- Удобный выбор языка в боковой панели.

### 📜 История чатов

- Все диалоги сохраняются в виде тредов, доступных для просмотра и удаления.

- Единая страница «История» объединяет диалоги помощников и сотрудников с фильтрами и поиском.

### ⚙️ Настройки

- Гибкая конфигурация API-ключей и параметров (endpoint, модель, температура) с возможностью тестирования соединения на лету.

- DevAgent/Сотрудник-специфичные настройки (модели, промпт, эконом-режим, функции, инструкции, навыки, базы знаний, подключения) - на отдельной странице настроек сотрудника.

## 📦 Установка и запуск

1. **Клонируйте репозиторий:**

```
git clone https://github.com/TVD2100/sagaai-platform sagaai  
cd sagaai
```

2. **Установите зависимости:**

```
pip install -r requirements.txt
```

3. **Запустите приложение:**

```
streamlit run app.py
```

4. Откройте браузер и перейдите по адресу [http://localhost:8501](http://localhost:8501/).

### 🔐 Включение защиты паролем

По умолчанию приложение работает без аутентификации. Если вы хотите ограничить доступ, задайте переменную окружения `SAGAAI_AUTH_PASSWORD` перед запуском:

```
export SAGAAI_AUTH_PASSWORD="ваш_надёжный_пароль"  
streamlit run app.py
```

После этого интерфейс будет показывать форму входа. Пароль не хранится в базе данных и не записывается на диск - сверка выполняется по SHA-256 хешу через `secrets.compare_digest`.

### 🔒 Настройка TLS-верификации

По умолчанию все HTTPS-запросы к AI-сервисам проверяют сертификаты (`verify=True`). Отключать проверку **не рекомендуется** (риск MITM-атаки), но при необходимости (корпоративный прокси, самоподписанный CA) это можно сделать через переменную окружения:

```
export SAGAAI_VERIFY_TLS=false   # не рекомендуется  
streamlit run app.py
```

### 🔑 Ключ для восстановления API-ключей

API-ключи, сохраняемые в базе данных, восстанавливаются с помощью отдельного ключа, который хранится **вне** папки с данными: доступ к файлам БД сам по себе не даёт доступа к сохранённым ключам.

Приоритет источников ключа:

1. **Переменная окружения `SAGAAI_ENCRYPTION_KEY`** - способ для серверов, при котором ключ не попадает на диск.

2. **Файл `~/.sagaai/encryption_key`** (путь можно переопределить через `SAGAAI_KEY_FILE`). Создаётся автоматически при первом запуске с правами `0600`.

3. **Автоматическая миграция**: если ключ раньше хранился рядом с БД (`DATA_DIR/.encryption_key`), он будет перенесён во внешний файл и удалён из папки данных при первом запуске.

Пример задания ключа через переменную окружения:

```
export SAGAAI_ENCRYPTION_KEY="$(python -c 'import secrets; print(secrets.token_urlsafe(32))')"  
streamlit run app.py
```

> ⚠️ **Важно:** если ключ будет утерян или заменён, ранее сохранённые API-ключи станут недоступными, и их придётся ввести заново. Храните ключ в надёжном месте (менеджер паролей, secrets-хранилище).

## 📁 Структура проекта

| Пакет | Назначение |
| - | - |
| `app.py` | Точка входа Streamlit |
| `core/` | Бизнес-логика (API, файлы, помощники, потоки, i18n, **оркестраторы**, **RAG**, **аутентификация**, **криптография**) без зависимостей от Streamlit |
| `ui/` | Интерфейсные страницы и компоненты (чат, сотрудники, история, настройки, помощники, **хранилище RAG**, **статистика**, **коннекторы**, **библиотека навыков**) |
| `storage/` | SQLAlchemy ORM-модели и репозиторий для SQLite |
| `dev_agent/` | Агентный цикл, безопасный писатель, инструменты, подбор сервисов для помощников, внешняя память задач |
| `defaults/` | Канонические копии: промпты оркестраторов, переводы, описания сервисов, пресеты, навыки, RAG-базы |
| `orchestrators/` | Рабочие папки оркестраторов (bundle, инструкции, функции) |
| `skills/` | Рабочая библиотека навыков (`skills.json` + папки навыков) |
| `tests/` | Полный набор тестов (pytest) |
| `langs/` | Файлы переводов (en, ru, zh-CN) |
| `services/` | Описания AI-сервисов |


## 🛠️ Технологии

- **Язык:** Python 3.10+

- **Фреймворк:** [Streamlit](https://streamlit.io/)

- **База данных:** SQLite через SQLAlchemy

- **Векторный индекс RAG:** SQLite + косинусное сходство (эмбеддинги - Yandex Embeddings API)

- **Криптографические операции:** библиотека `cryptography`

- **Тестирование:** pytest

- **AI-провайдеры:** OpenAI-совместимые API (YandexAI, DeepSeek), GigaChat
